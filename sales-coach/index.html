Sales Coach

Every call you have ever had is already recorded. Every email is already in Gmail. Every outcome is already in the CRM. Nobody ever joins them up, so the same mistake gets made for a year. This joins them up, grades every call and every email against a fixed rubric, and keeps only the differences that actually separate the deals you won from the ones you lost.

Fireflies calls Gemini tone-tagged transcripts Gmail threads HubSpot outcomes Jev typed judgments SQLite one file
Part one

The three prompts

Run them in order. The first builds the database, the second grades it, the third turns the result into a plan for one specific call. Copy each one straight into an agent with the connectors attached.

Part two

The workbench

This is prompt 2's comparison step, running here in the page. It loads a demo book of business tagged the way Jev would tag it, then computes which differences survive the guard. Drop in your own dataset.json to run it against your real numbers. Nothing leaves the browser.

      A question only becomes a pattern when all three guards clear: the gap is
      at least the minimum, both groups have at least the minimum sample, and a
      two-proportion test comes in under the significance level. On the demo
      data the two flat questions stay flat even with the minimum gap dragged
      to zero, because the significance test keeps rejecting them. They only
      turn into advice once significance is pushed past 0.40, which is the
      point at which you are no longer testing anything. That is the failure
      this step exists to prevent, and it is worth seeing it happen.

      Part four
      
Running it on your own calls

    


    

      

        

          The pipeline that fills sales.db lives in the repository
          alongside this page. It needs five credentials: a Fireflies API key, a
          Gemini API key, a Gmail OAuth token with read scope, a HubSpot private
          app token, and a TypeSafe key for Jev.
        

        
# once
cp pipeline/.env.example pipeline/.env   # then fill it in

# build the database from the last 12 months
node pipeline/run-prompt1.mjs

# let Jev grade all of it, then write findings.md
node pipeline/run-prompt2.mjs

# one page before a call
node pipeline/run-prompt3.mjs --prospect steve@example.com

        

          Every step is resumable. Audio already on disk is not downloaded
          twice, calls already transcribed are not sent to Gemini twice, and an
          artifact that already has an answer is not sent to Jev twice. Stopping
          halfway through and starting again costs only the step it was on.
        

        

          Prompt 1 writes recordings of real customer conversations to
          ~/sales-coach/. It is one directory and one SQLite file,
          which is also how you delete it.
