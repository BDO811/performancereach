# Daily sweep

1. If `owner/STOP` exists, stop, log it and say so.
2. Use the cmo agent to brief the daily sweep.
3. Use director-community on its brief: community-escalation first, then community-comment-replier,
   community-dm-agent and community-lead-catcher.
4. Use director-sales on its brief: sales-lead-scorer, sales-call-booker for hot leads,
   sales-reminder, sales-follow-up, sales-crm-sync.
5. Use the cmo agent with both returns.
6. Run `/morning-page`.
