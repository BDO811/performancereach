# Held for voice review

Drafts that failed the voice check. A department adds an item here instead of quietly fixing the
draft. Nothing in this file goes out. Fix the draft yourself or tick one box, then tell the
orchestrator: "Process the held items in queue/held-for-voice-review.md."

## Format for every item

    ### H-YYYYMMDD-NN: <short title>
    - [ ] Fixed: send it on
    - [ ] Drop it
    - File: <drafts/... path>
    - Held by: <agent> for brief <B-YYYYMMDD-NN>
    - Rule it broke: <the rule, quoted from tone-rules.md or owner/brand-voice.md>
    - Line that failed: "<the exact line>"
    - Owner note: <what to change, if anything>
